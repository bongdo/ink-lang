# Vault

Декларация того, что нужно пользователю: фичи, элементы системы, связи, критерии.
**Ведёт агент** по словам пользователя: каждое утверждение — с цитатой и `ses_...`.
Агент не выдумывает требования; спорное остаётся в «Открытых вопросах».

## Формат

- Одна сущность — один файл.
- Связи — `[[имя-заметки]]`.
- Шапка:

```markdown
---
id: имя
статус: черновик | принято
---
```

- Разделы: «Что это», «Связи», «Критерии приёмки», «Открытые вопросы».
- Критерий приёмки — проверяемый сценарий, не «удобно» и не «красиво».
- `статус: принято` ставит пользователь, не агент.

## Разделы

- `features/` — что пользователь должен уметь.
- `system/` — из каких частей состоит система и где границы.

Точка входа — [[index]].
