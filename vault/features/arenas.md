# Arenas

## Что это

Блочная арена с невидимым аллокатором. Пользователь видит один блок; всё
остальное — фон:

```ink
arena {
    var p = new[Point]();
    var xs = make[i32](8);
};
```

- `new[T]()` и `make[T](n)` внутри блока берут память из арены;
- снаружи это обычные Go-аллокации;
- free — на выходе из блока, включая return/break/continue/panic;
- `par` и `par for` внутри разрешены; аллокации (`new`/`make`) — только до
  `par`, потому что Go-арена не потокобезопасна; воркер может открыть свою
  `arena { ... };`;
- арены вкладываются и освобождаются изнутри наружу; значение из внутренней
  нельзя положить во внешнюю;
- память арены не покидает блок: sema отвергает присваивание
  captured-переменной, `return`, `&T{}`, аргумент/получатель вызова и `defer` с
  аренным значением;
- читать можно: поле, индекс, `len`/`cap`/`min`/`max`, копию структуры или
  массива без ссылок, `copy` наружу при скалярном элементе;
- воркер пишет аренный элемент по своему индексу (`rows[y] = row`); индекс из
  другого цикла отвергается как captured write.

Компилятор сам ставит `GOEXPERIMENT=arenas`, держит `Arena`, `Free` и mark.
Go-арена остаётся экспериментальной.

## Критерии приёмки

- `arena { new[Point](); make[i32](8); }` собирается и работает с
  `GOEXPERIMENT=arenas`.
- `par for` внутри арены заполняет заранее выделенный буфер; результат
  совпадает с последовательным заполнением (`tests/cases/arena_par`).
- `new`/`make` внутри `par` внутри арены отвергаются sema.
- Воркер может открыть свою `arena { ... };`, вложенные арены работают.
- Арена на функции (`fn f() arena`) отвергается.
- `ink check --json` и `ink run` не требуют ручной установки env.
- Память арены не передаётся в функции: `f(p)` и `p.Move()` отвергаются.
- Кадр: строки в арене, `par for` по строкам, `copy` в постоянный буфер,
  upload вне блока (`examples/frame`, `tests/cases/arena_par`).
- Значение, ушедшее из блока, документировано как use-after-free.

## Открытые вопросы

- Нужны ли функции, принимающие арену (borrow/тип), чтобы не инлайнить
  заполнение в тело воркера?
- `&T{}` внутри арены остаётся ошибкой; непонятно, нужен ли heapify вместо неё.
- Go-арена экспериментальная: API может измениться или исчезнуть.
