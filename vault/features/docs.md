# Docs

## Что это

Документов должно быть мало, и они делятся на два слоя:

- `vault/` — декларация продукта, которую агент ведёт по словам пользователя;
- `docs/` — поддержание: решения, реализация, руководства, архив.

Внутри `docs/`:

- `product/` — SPEC, PAR, FFI, FEATURES, EDGES;
- `maintain/` — decisions, IMPL;
- `guides/` — getting-started, lsp;
- `archive/` — только если история нужна; иначе удалять.

Никаких презентаций и устаревших proposals в живом дереве.

## Критерии приёмки

- В живом дереве не больше 10–12 markdown-файлов.
- `docs/README.md` — единственный вход.
- Нет `docs/archive` с устаревшими презентациями и proposals.
- `vault/` содержит фичи и систему, каждая с цитатой и критерием.
- Новая фича начинается в `vault/`, а не в `docs/`.
