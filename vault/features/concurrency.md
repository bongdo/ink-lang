# Concurrency

## Что это

Одно ключевое слово `go` и никакой скрытой многопоточности.

```ink
go {
    a = loadA()
        or fail;
    b = loadB()
        or fail;
};

go for (var i = 0; i < len(xs); i += 1) limit 4 {
    out[i] = work(xs[i]);
};

go save(1, "hello");        // detached task
```

- `go { }` — воркер на каждый top-level statement, join на блоке.
- `go for` — воркер на итерацию, `limit N` необязателен (по умолчанию
  `GOMAXPROCS`), тело итерации последовательное; range по map запрещён.
- `go f(args);` — отсоединённая задача, принадлежит программе и переживает
  вызывающую функцию; `f` возвращает `void` или `void!`; аргументы
  вычисляются до старта, замыкания нет.
- `on err { ... };` первым оператором функции/блока — слушатель
  необработанных ошибок `go`; после выражения — обработчик этого выражения.
  Слушатель не бывает пустым и не может использовать `return`; `fail`
  поднимает ошибку в объемлющую функцию, в detached-задаче паникует.
- `go`/`go for` ждут все воркеры и не отменяют соседей; на join отдаётся
  ошибка с низшим ordinal — в слушатель области или из функции.
- Паника — Go паника: `on err` её не ловит, `go` не восстанавливает; процесс
  падает со стеком.
- Скрытого контекста нет: `ctx` — обычное значение, передаётся явно в те
  Go-API, которым он нужен. `within` удалён: дедлайн —
  `context.WithTimeout`.
- Fallible-вызов голым оператором запрещён: `f();` теряет ошибку, нужно
  `f() on err { }`, `f() or fail` или явное `_ = f();`.

## Критерии приёмки

- `go { }`, `go for ... limit N` и `go f(args);` проходят `ink check` и
  собираются.
- `go { }` и `go for` ждут всех воркеров; ошибка детерминирована по низшему
  ordinal; досрочной отмены нет.
- `go f()` переживает обработчик; необработанная ошибка уходит в `on err`
  области запуска или роняет программу.
- `on err { }` первым оператором — слушатель; пустой блок и `return` дают
  ошибку, `fail` поднимает ошибку вызывающему.
- Паника не ловится `on err` и не заворачивается в `go`.
- `par`, `within`, `or err`, `or panic`, `on fail` отвергаются с подсказкой
  о новой форме.
- `ctx` — обычное значение: нет `_ctx`-обёрток, нет цветных функций.
- Fallible-вызов голым оператором отвергается; `_ = f();` разрешён.
- `ink run -race` и `ink test -race` остаются динамическим оракулом.

## Открытые вопросы

- Пул/очередь в язык не входят: фоновая задача — `go f()`, пул остаётся
  Go-адаптером. Вернуться, если появится сценарий, который `go f()` не
  покрывает.
