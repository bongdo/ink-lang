# Tooling

## Что это

Обратная связь важнее фич. Агент должен работать по `ink check --json` и LSP,
не читая исходники компилятора.

- `ink check --json`: `file`, `line`, `col`, `endLine`, `endCol`, `code`,
  `message`, `hint`;
- LSP берёт парсер, sema, typecheck и форматтер у компилятора;
- расхождение LSP и компилятора исключается общим снимком анализа;
- слепые тесты: агент решает задачу без документации и сообщает, где споткнулся.

## Критерии приёмки

- Диагностика LSP содержит `code`, `message` и `hint`; тот же код, что в
  `ink check --json`.
- Ответ LSP не строится по устаревшей версии буфера.
- `rename` не выдаёт edit, если имя уже занято в области видимости.
- Слепой тест: сломанный проект чинится только по диагностике, без docs.
- Слепой тест: новая программа пишется по `ink guide` и проходит `check`.
