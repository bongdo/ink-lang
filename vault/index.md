# Ink

Язык приложений на Go: компилируется в Go, живёт на Go runtime, сохраняет
Go-экосистему, но даёт короткую и предсказуемую поверхность. Главный
потребитель — агент: он должен писать код без догадок, получать точную
диагностику и чинить её без чтения исходников компилятора.

## Фичи

- [[syntax]] — один канонический способ, `T!`, `or fail`, литералы `:`.
- [[errors]] — обработка ошибок легче Go, без `if err != nil`.
- [[arenas]] — блочные арены с невидимым аллокатором.
- [[tooling]] — `ink check --json`, LSP на компиляторе, слепые тесты.
- [[docs]] — product/maintain, меньше документов, nit-gui как образец.

## Система

- [[architecture]] — компилятор → Go, LSP как адаптер анализа.
- [[constraints]] — Go-граница, каналы, экспериментальные арены.
