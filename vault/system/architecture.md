# Architecture

## Что это

Компилятор переводит `.ink` в Go и отдаёт `go build`/`go test`. LSP — тонкий
адаптер к тому же анализу, а не второй компилятор.

- парсер, sema, typecheck, форматтер — общие пакеты;
- LSP не печатает типы и не режет текст своими руками;
- диагностика несёт `code`, `message`, `hint`, `fix`;
- `go.mod` — кандидат на единственный проектный файл вместо `ink.conf`.

## Критерии приёмки

- Hover, completion и signature help используют один печататель типов с codegen.
- Code actions берут фиксы из диагностики, а не переписывают текст в LSP.
- `ink.conf` удалён; `go.mod` даёт module, go version и корень проекта.
- `ink new` создаёт `go.mod`, `main.ink`, `AGENTS.md`, `opencode.json`, skill.
